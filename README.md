# Unity AI Agent

Drop-in Unity Editor AI Agent package.

## Quick start

1. Copy `Assets/UnityAgent` into your Unity 6 project.
2. Optionally copy `UNITY_AGENT.md` to the project root.
3. Install & run [Ollama](https://ollama.com), pull a model, set its name in **Project Settings → AI Agent**.
4. Open **Window → AI Agent**.

Full docs: [`Assets/UnityAgent/README.md`](Assets/UnityAgent/README.md)
